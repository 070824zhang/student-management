# 学生信息管理系统

> 一个基于 Python + CSV 文件存储的命令行学生信息管理系统，支持增、删、改、查，ID 自动生成。

## 功能
基础功能基本完善
- ✅ 添加学生（自动生成唯一 ID）
- ✅ 删除学生（根据 ID）
- ✅ 修改学生信息（姓名、性别、年龄、地址）
- ✅ 查询学生（根据 ID）
- ✅ 数据持久化（存储为 students.txt，CSV 格式）

## 技术栈

- Python 3.13
- 文件读写（CSV 格式）
- 命令行交互

## 运行方法

```bash
python student-management.py
